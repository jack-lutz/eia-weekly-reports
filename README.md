# EIA Weekly Energy Report

Automated weekly report on U.S. petroleum inventories using EIA data.

**Status:** work in progress

## Done so far
- Pulls weekly U.S. distillate stocks directly from EIA
- Week-over-week change
- Comparison to the 5-year average for the same week
- Seasonal chart: current year vs. 5-year range and average

## Coming next
- Gasoline and crude stocks, refinery utilization
- Diesel crack spread (NY Harbor ULSD vs. WTI)
- One-page Excel report
